# 測試用例

## Test 1：單個 PDF 檔案（銷售季度總結）

### 場景設定
- **上傳檔案**：銷售季度總結.pdf（20 頁）
- **檔案內容**：
  - P1-2：封面和目錄
  - P3-5：市場概況（含 3 張圖表）
  - P6-10：銷售數據（含 4 個表格，如地區別銷售額、產品別營收等）
  - P11-15：問題分析（文字 + 1 張對比圖）
  - P16-20：建議和下一步（文字為主）

### 預期行為
1. ✓ Skill 提問：簡介版/標準版/詳述版
2. ✓ Skill 推薦：標題頁、內容頁、結束頁結構
3. ✓ Skill 推薦：表格重繪、圖表保留或重繪
4. ✓ 用戶確認後，生成對應頁數的 PPTX

### 驗證重點
- 是否正確識別 PDF 中的表格和圖表？
- 是否按規模推薦合理的頁數壓縮？（20 頁 PDF → 對應版本的頁數）
- 是否推薦合理的內容轉換方案？

## Test 2：混合檔案（Excel + Word + 圖片）

### 場景設定
- **上傳檔案 1**：成本分析.xlsx
  - Sheet1：2025 年成本預算（10 行×8 列表格）
  - Sheet2：月度成本趨勢（柱狀圖）
  
- **上傳檔案 2**：市場背景.docx
  - 3 段文字說明市場趨勢
  - 1 張行業報告截圖
  
- **上傳檔案 3**：競品對比.jpg（單張圖片）

### 預期行為
1. ✓ Skill 提問：這三個檔案的邏輯關係？應如何組織？
2. ✓ Skill 推薦：頁面結構（例：成本表 → 成本趨勢圖 → 市場背景 → 競品對比）
3. ✓ Skill 推薦：Excel 表格如何處理、Word 文字如何分段、圖片如何嵌入
4. ✓ 用戶確認後，生成整合的 PPTX

### 驗證重點
- 是否要求用戶澄清多檔案的組織邏輯？
- 是否給出合理的頁面流程建議？
- 是否正確識別 Excel 數據表和圖表？

## Test 3：遇到歧義的場景（數據衝突）

### 場景設定
- **上傳檔案**：Q3_銷售報告.xlsx
  - Sheet「月度銷售」：Q3 銷售額 = 1,200 萬
  - Sheet「季度總結」：Q3 銷售額 = 1,150 萬
  - 差異原因：一個表包含退貨，一個不包含

### 預期行為
1. ✓ Skill 在生成過程中發現數據不一致
2. ✓ Skill **停下來提問**，不要自作聰明選擇其中一個
3. ✓ 提問格式：清楚指出兩個數據，問用戶應該用哪個

### 驗證重點
- 是否會盲目選擇第一個遇到的數據？
- 是否會停下來提問澄清？
- 提問是否清楚無歧義？

## 評估標準

每個 Test 完成後檢查：

- [ ] Skill 是否遵循四階段流程？（確認規模 → 推薦規格 → 推薦方案 → 執行）
- [ ] Skill 是否正確推薦設計規格（字體、顏色、版式）？
- [ ] Skill 是否給出具體的內容轉換建議？
- [ ] 遇到不確定時，Skill 是否停下提問而不是補充內容？
- [ ] 最終 PPTX 是否符合設計規範（思源黑體、淡雅專業純色背景、頁碼、高管目標）？
