# 格式預設標準（Fallback Defaults）

本文件整理兩類數值：
- **A 類（文字外觀 fallback）**：只有當參考範本沒有定義對應樣式/層級時才套用。
  參考範本若有定義，永遠以範本為準，並在驗證報告標註「已套用範本值，非 fallback」。
- **C 類（文件慣例）**：與參考範本/原始檔無關，一律套用（除非與「原始檔頁首頁尾結構不可更動」
  或「橫向頁不可套直向邊界」等硬規則衝突，衝突時硬規則優先，見 SKILL.md「停止條件」）。

---

## A 類：具名樣式 fallback

| 樣式 | 中文字型 | 英文/數字字型 | 字級 | 顏色 | 粗細 | 段前 | 段後 |
|---|---|---|---|---|---|---|---|
| 標題 1 | 標楷體 | Times New Roman | 16pt | 黑色 (000000) | 粗體 | 0 行 | 0 行 |
| 標題 2 | 標楷體 | Times New Roman | 14pt | 黑色 (000000) | 粗體 | 0 行 | 0 行 |
| 副標題 | 標楷體 | Times New Roman | 13pt | 黑色 (000000) | 粗體 | 0 行 | 0 行 |
| 內文 | 標楷體 | Times New Roman | 12pt | 黑色 (000000) | 正常 | 0 行 | 0 行 |

> 字級換算：OOXML `w:sz` 單位為半磅，12pt → `w:sz="24"`。

## A 類：多層次清單縮排 fallback（最多五層）

| 層級 | 編號/符號格式 fallback | 左縮排 | 首行/Hanging | 段前/段後 |
|---|---|---|---|---|
| 1（ilvl 0） | `%1.`（阿拉伯數字＋句點，如 1.） | 左 1 字元 | 0 | 0 行 / 0 行 |
| 1.1（ilvl 1） | `%1.%2.`（如 1.1） | 左 2 字元 | 0 | 0 行 / 0 行 |
| 1.1.1（ilvl 2） | `%1.%2.%3.`（如 1.1.1） | 左 3 字元 | 0 | 0 行 / 0 行 |
| A.（ilvl 3） | 大寫英文字母＋句點（A. B. C.） | 左 4 字元 | 0 | 0 行 / 0 行 |
| a.（ilvl 4） | 小寫英文字母＋句點（a. b. c.） | 左 5 字元 | 0 | 0 行 / 0 行 |

右縮排（`w:rightChars`）一律 0 字元（spec 原文「右0字元」）。

> 縮排換算：OOXML 字元縮排單位為「百分之一字元」，即 `w:leftChars="100"` = 左縮排 1 字元。
> 此換算為 OOXML 慣例假設，尚未對照真實 Word 顯示效果驗證，見 SKILL.md「已知限制」。

## C 類：文件慣例（一律套用）

### 版面邊界（僅套用於直向頁）

| 邊界 | 數值 | 換算 twips（1 cm ≈ 566.93） |
|---|---|---|
| 上 | 1.27 cm | 720 |
| 下 | 1.44 cm | 816 |
| 左 | 1.95 cm | 1106 |
| 右 | 1.27 cm | 720 |

橫向頁（`w:pgSz w:orient="landscape"`）：完全保留原始檔設定，不套用上表，不翻轉方向。

### 日期格式

一律「西元年/月/日」，月、日皆兩位數補零，例：`2023/01/10`。

- 若偵測到民國年格式（如 `112年1月10日`、`112/01/10`），換算公式：西元年 = 民國年 + 1911。
- 偵測範圍僅限內文（document.xml body），不含頁首頁尾（頁首頁尾結構不可更動）。

### 版次規則

- 格式：`X.Y`（主版號.次版號）。
- 首次制訂：`1.0`。
- 小改：`1.0 → 1.1 → 1.2 → … → 1.9`，超過 `.9` 後升主版號（如 `1.9 → 2.0`）。
- 重大改版或系統整合：主版號可直接跳升（如 `1.2 → 2.0`），不受次版號是否到 `.9` 限制。
- 腳本只檢查現有字串是否符合 `X.Y` 格式；是否該跳版號由使用者依「改動幅度」自行判斷。

### 頁碼

- 一至三階文件自首頁起編列，格式 `n/總頁數`，置於頁尾。
- 僅在原始檔頁尾已存在對應欄位時正規化格式；頁尾原本沒有欄位時不新增（見 SKILL.md 硬規則）。

### 表單編號

- 於頁尾賦予「表單編號」。
- 同頁碼規則：僅正規化既有欄位，不新增頁尾結構。
