# 大眾運輸路線（國外預設；台灣指定時使用）

原本 `transit-route-links` skill 的流程，移到這裡。目標：用最少的來回，給出「去哪個站牌、搭哪一線、往哪個方向、在哪下車」。

## 1. 起點與目的地
沿用 SKILL.md 步驟 1、3。起點與目的地距離約 800 公尺內，直接建議走路。

## 2. 查路線與乘車處
- **日本**：用日文關鍵字搜尋，例如「<最近地名> バス停 <目的地>」「<站牌名> 時刻表」「<目的地> 行き のりば」。乘換案內類網站（例如 jorudan）的站牌頁通常列出：系統編號、方向、終點乘車處代號（如 博多駅前A、F）。
- **台灣**：查捷運站出口、公車路線號碼與站牌名稱（各縣市公車動態網站、台鐵／高鐵官網）。
- 需要寫明：
  - 最近的上車站牌或車站（當地正式名稱）
  - 路線編號與行駛方向（看站牌時要找哪一側）
  - 下車站與乘車處代號、出口（大型車站各出口位置差很多）
- 有地鐵、鐵路等替代方案時一併列出，並比較走路時間。
- 大型轉運站（巴士總站、車站）盡量查出樓層與乘車處號碼；查不到就明確說查不到。

## 3. 連結
沿用 SKILL.md 步驟 5，使用大眾運輸模式。另外可加：
- 站牌位置：Apple `https://maps.apple.com/?ll=<緯度>,<經度>&q=<站牌名>`；Google `https://www.google.com/maps/search/?api=1&query=<緯度>,<經度>`。座標照 SKILL.md 步驟 3.5 取得，兩個連結座標必須相同；查不到座標才退回只用站牌名，並標示「未經雙來源核對」。
- 日本地名在網址中用日文。

## 4. 回覆格式
1. 一句話：目前位置與距離目的地多遠
2. 建議方案（站牌、路線、方向、下車處、出口），有替代方案就簡列
3. 連結：Apple 在前、Google 在後
4. 必要時問一句下一步

## 誠實原則
- 搜尋到的時間是**表定時刻**，不是即時動態，要讓使用者知道；即時資訊請看 Google 地圖（有顏色標示的時間才是即時）或業者的巴士位置查詢服務。
- 沒查到具體班次時間，直接說沒查到，交給 Google 地圖連結顯示下一班。
- 對 Apple 地圖在當地巴士資料的完整度沒有把握時要標註。
- 站牌位置、樓層、乘車處號碼不確定，一律說「我不確定」。
